## プロジェクトの概要

「旅行先を決めきれない」という場面で、選択した都道府県の中から行き先をルーレット形式で決めるアプリです。サーバーやデータベースを使用せず、ブラウザだけで動作します。

### 主な機能

- 日本全国47都道府県から旅行先をランダム抽選
- 地方単位・都道府県単位で抽選対象を選択
- 全都道府県の一括選択・一括解除
- 訪問済み・未訪問の状態管理
- 未訪問の都道府県だけを対象にした抽選
- 日本地図上で抽選中の候補と決定した旅行先を表示
- 直近5件の抽選履歴を保存・表示
- 日本語、英語、中国語、韓国語の4言語に対応
- 選ばれた都道府県の観光・宿泊・グルメ検索
- Web Share APIによる結果共有
- クリップボードへの結果コピー
- PC・スマートフォンに対応したレスポンシブ表示

## 使用している主な技術

## 開発環境の構築方法

### 1. プロジェクトへ移動

```bash
cd randtravel
```

### 2. ローカルHTTPサーバーを起動

```bash
python3 -m http.server 8000
```

### 3. ブラウザで確認

<http://localhost:8000/> を開きます。

ソースを変更したらブラウザを再読み込みしてください。ビルド処理や開発サーバーの再起動は必要ありません。

> `index.html` を直接開いても基本機能は動作しますが、ブラウザのセキュリティ制限により共有・クリップボード機能が制限される場合があります。ローカルHTTPサーバー経由での確認を推奨します。

## 使い方

1. 画面右上で表示言語を選択します。
2. 地方または都道府県ごとのチェックボックスで抽選対象を選びます。
3. 必要に応じて、訪問済みの都道府県を登録します。
4. 未訪問地だけから選びたい場合は「未訪問のみで抽選」を有効にします。
5. 「旅先を決める」を押すと、約2.6秒のルーレット後に旅行先が決定します。
6. 結果画面から観光情報、宿泊施設、グルメを検索できます。
7. 「共有」または「結果をコピー」で抽選結果を共有できます。

最新5件の結果は「抽選履歴」に表示されます。

## データ保存と外部通信

### LocalStorageに保存する項目

| キー | 内容 |
| --- | --- |
| `preferredLanguage` | 選択中の表示言語 |
| `selectedPrefectures` | 抽選対象の都道府県 |
| `visitedPrefectures` | 訪問済みの都道府県 |
| `rouletteHistory` | 直近5件の抽選結果 |
| `unvisitedOnly` | 未訪問のみで抽選する設定 |

これらのデータは利用中のブラウザ内だけに保存され、アプリ独自のサーバーには送信されません。LocalStorageが利用できない場合も、保存機能なしでアプリを使用できます。

### 外部サイトへのリンク

抽選後のボタンから、選ばれた都道府県名を使ってGoogle検索を開きます。また、Yahoo!トラベルとじゃらんへのアフィリエイトリンクを表示します。外部サイトを開くまでは、検索や予約に関する通信は行いません。

## デプロイ

静的ファイルを配信できるサービスへ `index.html` を配置するだけで公開できます。

- GitHub Pages
- Cloudflare Pages
- Netlify
- Vercel
- 任意のWebサーバー

ビルドコマンドは不要で、公開ディレクトリはプロジェクトのルートです。クリップボードや共有などのブラウザAPIを安定して利用するため、公開環境ではHTTPSを使用してください。

## トラブルシューティング

### ページを開けない

ローカルHTTPサーバーを起動したターミナルが動作中か確認し、<http://localhost:8000/> を開いてください。`index.html` のあるディレクトリでコマンドを実行する必要があります。

### `Address already in use` と表示される

ポート8000が別のアプリで使用されています。別のポートで起動してください。

```bash
python3 -m http.server 8080
```

起動後は <http://localhost:8080/> を開きます。

### 抽選を開始できない

- 抽選対象の都道府県を1つ以上選択してください。
- 「未訪問のみで抽選」が有効な場合、選択中の都道府県がすべて訪問済みだと抽選できません。訪問済みを解除するか、設定をオフにしてください。

### 設定や履歴が保存されない

- ブラウザでLocalStorageが無効になっていないか確認してください。
- シークレットブラウジングでは、ウィンドウを閉じたときにデータが消える場合があります。
- URLのホスト名やポートが変わると保存領域も変わります。同じURLで開いてください。
- ブラウザのサイトデータを削除すると、訪問状況や履歴も消去されます。

### 共有ボタンが共有画面を開かない

Web Share APIに対応していないブラウザでは、結果をクリップボードへコピーします。コピーも失敗する場合は、HTTPSまたは `localhost` で開き、ブラウザの権限設定を確認してください。

### 観光・宿泊・グルメのリンクを開けない

ブラウザのポップアップ防止機能、広告ブロッカー、コンテンツフィルターが外部リンクを制限していないか確認してください。
